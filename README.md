# GameStore

GameStore — проект информационной системы интернет-магазина компьютерных игр. Система предназначена для поиска и покупки игр, управления библиотекой пользователя и оформления возврата средств. Администратор системы может управлять каталогом игр и обрабатывать связанные с магазином операции.
